# AMR Shield

**Symptom-Driven, Multi-Model Antibiotic Resistance Decision Support System**

AMR Shield accepts a list of clinical symptoms and returns predictions from three
independently trained classifiers (Logistic Regression, Random Forest, XGBoost),
a final authoritative prediction, and a model-agreement flag — giving clinicians
both a recommendation and a confidence signal.

---


## Setup

### 1. Create and activate a virtual environment

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment variables

```bash
cp .env.example .env
# Edit .env and fill in your values
```

### 4. Train the models

1. Download the [Kaggle Disease-Symptom dataset](https://www.kaggle.com/) and place
   the CSV file in `data/raw/`.
2. Open and run `notebooks/model_training.ipynb` top-to-bottom.
3. Confirm that six `.pkl` files appear in `backend/models/`.

### 5. Run the Flask server

```bash
# From the amr-shield/ directory
python -m backend.app
```

The API will be available at `http://localhost:5000`.

## API Reference

### GET /api/v1/health

Returns service status and model-load confirmation.

**Response**
```json
{
  "status": "healthy",
  "models_loaded": true,
  "version": "1.0.0",
  "timestamp": "2024-01-01T00:00:00.000000+00:00"
}
```

---

### POST /api/v1/predict

Accepts a symptom list and returns multi-model predictions.

**Request body**
```json
{
  "symptoms": ["fever", "dysuria", "frequent_urination", "burning_micturition"]
}
```

**Success response (HTTP 200)**
```json
{
  "status": "success",
  "comparison": {
    "Logistic Regression": { "prediction": "UTI", "confidence": 0.7134 },
    "Random Forest":       { "prediction": "UTI", "confidence": 0.8421 },
    "XGBoost":             { "prediction": "UTI", "confidence": 0.9187 }
  },
  "final_prediction": "UTI",
  "model_agreement": true,
  "timestamp": "2024-01-01T00:00:00.000000+00:00"
}
```

**Error response (HTTP 400)**
```json
{
  "status": "error",
  "message": "\"symptoms\" must be a non-empty list of symptom strings."
}
```

## Environment Variables

| Variable            | Description                          | Default                      |
|---------------------|--------------------------------------|------------------------------|
| `DB_HOST`           | MySQL host                           | `localhost`                  |
| `DB_PORT`           | MySQL port                           | `3306`                       |
| `DB_NAME`           | MySQL database name                  | `amr_shield`                 |
| `DB_USER`           | MySQL username                       | `root`                       |
| `DB_PASS`           | MySQL password                       | *(empty)*                    |
| `WHO_GLASS_BASE_URL`| WHO GLASS API base URL               | `https://glass.who.int/api`  |
| `CACHE_TTL_HOURS`   | Cache time-to-live in hours          | `24`                         |
| `FLASK_ENV`         | `development` or `production`        | `production`                 |
| `PORT`              | Port the Flask server listens on     | `5000`                       |
